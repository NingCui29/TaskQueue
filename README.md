# TaskQueue Maven 依赖仓库

此分支仅存放正式发布的依赖产物。源码、使用说明及更新日志见：https://github.com/NingCui29/TaskQueue

Gradle 仓库地址：https://raw.githubusercontent.com/NingCui29/TaskQueue/maven

按运行平台选择一种依赖：
- JVM JAR：com.cn.tasks:TaskQueue:0.1.0
- Android AAR：com.cn.tasks:TaskQueue-android:0.1.0

两种依赖包含相同核心类，不要在一个应用中同时引入。正式发布后的版本固定保留，后续变更使用新版本号。
